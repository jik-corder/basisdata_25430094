# Identitas Proyek

* **Tema Proyek**: Toko Sepatu Online (Sesuai Digit NIM 94)
* **Nama Organisasi**: Sepatu Sport AGA 094
* **Lingkup Layanan**: 
  Sepatu Sport AGA 094 menyediakan layanan penjualan sepatu olahraga secara online, mencakup pengelolaan inventaris produk, pencatatan transaksi pembelian pelanggan, hingga manajemen pengiriman barang secara efisien.
