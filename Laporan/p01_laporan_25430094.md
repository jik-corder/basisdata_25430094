## Titik Analisis

### 1. Dampak Karakter Set dan Collation
* **Penjelasan:** Penggunaan `utf8mb4` memungkinkan MariaDB/MySQL menyimpan seluruh cakupan karakter Unicode (termasuk huruf multibyte, simbol khusus, dan emoji). Collation `utf8mb4_unicode_ci` bersifat *case-insensitive* (tidak membedakan huruf besar dan kecil saat pencarian) dan mengikuti standar pengurutan Unicode internasional yang akurat.

### 2. Keamanan Akun Root
* **Penjelasan:** Membiarkan akun `root` tanpa password sangat berbahaya karena siapa saja yang memiliki akses jaringan atau terminal lokal dapat mengubah, menghapus, atau mengambil seluruh data dalam database tanpa otentikasi.

### 3. Aspek Keamanan Pembuatan User Baru dan Hak Akses
* **Penjelasan:** Prinsip *least privilege* diterapkan dengan hanya memberikan hak akses (`GRANT ALL PRIVILEGES ON kopma_094.*`) khusus pada database `kopma_094` saja. Pengguna `abizar_094` tidak diberikan akses ke database sistem atau database milik pengguna lain.

### 4. Perbedaan Menggunakan Shell XAMPP vs Command Prompt Biasa
* **Penjelasan:** Shell XAMPP sudah mengonfigurasi jalur variabel lingkungan (*environment path*) secara otomatis ke direktori `xampp/mysql/bin`, sehingga perintah `mysql` dapat dipanggil secara langsung tanpa perlu masuk ke folder instalasi atau mengatur variabel lingkungan Windows secara manual.
